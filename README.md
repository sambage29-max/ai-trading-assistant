# AI-Driven Advanced Trading Architecture

An institutional-grade systematic algorithmic trading suite built using Streamlit and predictive convergence engines.

## Architecture Ecosystem
- `app.py`: High-fidelity UI & multi-timeframe dashboard.
- `indicators.py`: Vectorized technical indicators (RSI, MACD, BB, ATR).
- `ai_engine.py`: Dynamic conditional execution & risk management.
- `cron_scan.py`: Standalone market scanner for continuous monitoring.
- `test_bot.py`: Verification and test coverage matrix.

## Deployment Instructions
1. Commit all files to your production branch on GitHub.
2. Link the repository to Streamlit Cloud.
3. The platform will read `requirements.txt` and launch automatically.
